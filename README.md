# 🌱 SoyVision

### Computer Vision for Grain Analysis

**SoyVision** is an applied Computer Vision project created to investigate the automated analysis and classification of grain samples using high-resolution images and instance segmentation.

The project explores the complete computer vision pipeline:

```text
Image Acquisition
       ↓
Dataset Construction
       ↓
Instance Annotation
       ↓
AI-assisted Pre-annotation
       ↓
Human Review
       ↓
YOLO11 Instance Segmentation
       ↓
Multiclass Classification
       ↓
Inference & Post-processing
       ↓
Grain Counting & Sample Analysis
```

### 🔬 Research & Engineering

The project combines:

- **YOLO11-seg** for instance segmentation
- **OpenCV** for image processing
- **CVAT** for dataset annotation and review
- **SAM** for annotation assistance
- **Transfer Learning**
- **Data Augmentation**
- **Tiling** for high-resolution dense images
- **Human-in-the-Loop annotation**
- **Active Learning strategies**
- **Dataset quality analysis**

### 📊 Experimental Dataset

<p align="center">
  <strong>500 images • 339,645 annotated instances • 4 initial classes</strong>
</p>

<p align="center">
  <code>Healthy</code> •
  <code>Impurity</code> •
  <code>Greenish</code> •
  <code>Broken</code>
</p>

The project is evolving from a Proof of Concept into a broader research and engineering platform for **AI-assisted grain quality analysis**.
